# 🤖 AI Career Copilot

> An AI-powered career platform that helps developers improve their resumes, prepare for interviews, analyze job descriptions, and plan their learning journey.

---

## 📌 Overview

AI Career Copilot is a full-stack web application built using the MERN ecosystem (MySQL + Sequelize) that combines Artificial Intelligence, authentication, real-time communication, and subscription-based features into a single platform.

The application enables users to:

- 📄 Analyze resumes using AI
- 🎯 Match resumes against Job Descriptions
- 🎤 Practice AI-powered mock interviews
- 💬 Chat with an AI career assistant
- 📈 Track career growth with dashboards
- 💳 Upgrade to Pro using Cashfree Payments

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/pwanjari23/AI_Career_Copilot.git
```

### Install

```bash
cd AI_Career_Copilot
npm install
```

### Environment Variables

Create a `.env` file and configure:

```
PORT=
JWT_SECRET=
DB_NAME=
DB_USER=
DB_PASSWORD=
GEMINI_API_KEY=
CASHFREE_CLIENT_ID=
CASHFREE_CLIENT_SECRET=
EMAIL_USER=
EMAIL_PASS=
```

### Run

```bash
npm run dev
```
